# Calculadora Python

Calculadora interactiva en Python con menú de opciones para sumar, restar, multiplicar y dividir.

# Cómo funciona

El programa muestra un menú en consola donde el usuario elige una operación, ingresa dos números, y obtiene el resultado. Incluye manejo del caso de división entre cero.

# Cómo ejecutarlo

1. Asegúrate de tener Python instalado
2. Descarga o clona este repositorio
3. Ejecuta en la terminal:

\`\`\`bash
python calculadora.py
\`\`\`

4. Sigue las instrucciones en pantalla

# Tecnologías

- Python 3
